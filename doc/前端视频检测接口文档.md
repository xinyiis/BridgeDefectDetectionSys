# 视频缺陷检测前端接口文档

## 📋 概述

本文档说明如何在前端实现视频缺陷检测功能，包括视频上传、实时进度展示、缺陷标注渲染等。

## 🚀 快速开始

### 完整流程

```
1. 上传视频 → 获取 task_id
2. 启动检测 → 获取 session_id 和 WebSocket URL
3. 建立 WebSocket 连接 → 接收实时进度和缺陷数据
4. 渲染缺陷标注框（bbox）到视频帧上
5. 任务完成 → 展示最终结果
```

## 📡 接口列表

### 1. 上传视频

**接口**: `POST /api/v1/detection/video/upload`

**请求**:
```http
Content-Type: multipart/form-data

bridge_id: 1
drone_id: 3
pixel_ratio: 0.5
video: <视频文件>
```

**响应**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "video_abc123...",
    "status": "uploaded",
    "video_path": "videos/xxx.mp4",
    "total_frames": 628,
    "fps": 30.0
  }
}
```

**字段说明**:
- `bridge_id`: 桥梁ID
- `drone_id`: 无人机ID
- `pixel_ratio`: 像素比例（米/像素），当前仅作为任务元数据保留，视频检测结果不返回实际尺寸量化值
- `task_id`: 任务唯一标识，后续所有操作都需要这个ID

---

### 2. 启动检测

**接口**: `POST /api/v1/detection/video/{task_id}/start`

**响应**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "video_abc123...",
    "session_id": "session_xyz789...",
    "status": "ready_to_process",
    "ws_url": "/api/v1/detection/video/ws?task_id=xxx&session_id=yyy"
  }
}
```

**字段说明**:
- `session_id`: 本次检测会话ID，用于 WebSocket 连接
- `ws_url`: WebSocket 连接地址

---

### 3. 查询任务状态

**接口**: `GET /api/v1/detection/video/{task_id}`

**响应**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "video_abc123...",
    "status": "processing",
    "processed_frames": 150,
    "total_frames": 628,
    "confirmed_defects": 5,
    "created_at": "2024-01-01T10:00:00Z"
  }
}
```

**任务状态说明**:
- `uploaded`: 已上传，等待启动
- `ready_to_process`: 已启动，准备处理
- `frame_extracting`: 正在提取视频帧
- `dispatching`: 正在分发检测任务
- `queued`: 已进入算法队列
- `processing`: 正在检测
- `completed`: 检测完成
- `failed`: 检测失败
- `canceled`: 已取消

---

### 4. 取消任务

**接口**: `POST /api/v1/detection/video/{task_id}/cancel`

**响应**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "video_abc123...",
    "status": "canceled"
  }
}
```

## 🔌 WebSocket 实时通信

### 连接地址

```
ws://your-domain/api/v1/detection/video/ws?task_id={task_id}&session_id={session_id}
```

### 消息类型

#### 1. 连接成功 (`connected`)

```json
{
  "type": "connected",
  "task_id": "video_abc123...",
  "session_id": "session_xyz789...",
  "message": "websocket connected"
}
```

#### 2. 帧检测结果 (`frame`) ⭐ 重点

这是渲染缺陷标注框的核心数据：

```json
{
  "type": "frame",
  "task_id": "video_abc123...",
  "session_id": "session_xyz789...",
  "frame_no": 143,
  "timestamp_ms": 4766,
  "processed_frames": 143,
  "total_frames": 628,
  "progress": 22.77,
  "defects": [
    {
      "defect_type": "渗水",
      "bbox": {
        "x": 768,
        "y": 146,
        "width": 48,
        "height": 252
      },
      "length": 0,
      "width": 0,
      "area": 0,
      "measurement_source": "none",
      "measurement_status": "unavailable"
    }
  ],
  "defect_count": 1,
  "queue_latency_ms": 14428,
  "detect_latency_ms": 21
}
```

**关键字段**:
- `frame_no`: 帧序号（从1开始）
- `timestamp_ms`: 视频时间戳（毫秒）
- `defects`: 该帧检测到的缺陷列表
- `bbox`: 缺陷边界框坐标（像素单位）
  - `x, y`: 左上角坐标
  - `width, height`: 宽度和高度
- `length, width, area`: 当前固定为 `0`，表示视频检测不提供实际尺寸量化结果
- `measurement_source = "none"` 且 `measurement_status = "unavailable"`：表示当前帧只有定位框，没有物理量化信息
- `defect_type`: 缺陷类型（渗水、裂缝、破损、孔洞等）

#### 3. 进度更新 (`progress`)

```json
{
  "type": "progress",
  "task_id": "video_abc123...",
  "session_id": "session_xyz789...",
  "processed_frames": 150,
  "total_frames": 628,
  "progress": 23.89,
  "total_defects": 5
}
```

#### 4. 检测完成 (`completed`)

```json
{
  "type": "completed",
  "task_id": "video_abc123...",
  "session_id": "session_xyz789...",
  "total_frames": 628,
  "total_defects": 12,
  "defect_summary": {
    "渗水": 8,
    "裂缝": 3,
    "破损": 1
  },
  "message": "视频分析完成"
}
```

#### 5. 错误通知 (`error`)

```json
{
  "type": "error",
  "task_id": "video_abc123...",
  "session_id": "session_xyz789...",
  "message": "queued 后连续无进度消息超时"
}
```

## 🎨 前端实现建议

### 1. 渲染缺陷标注框

当收到 `frame` 消息时，在对应的视频帧上绘制 bbox：

```javascript
// 示例：使用 Canvas 绘制
function drawDefects(canvas, defects) {
  const ctx = canvas.getContext('2d');
  
  defects.forEach(defect => {
    const { x, y, width, height } = defect.bbox;
    
    // 根据缺陷类型设置颜色
    const color = getColorByType(defect.defect_type);
    ctx.strokeStyle = color;
    ctx.lineWidth = 2;
    
    // 绘制矩形框
    ctx.strokeRect(x, y, width, height);
    
    // 绘制标签
    ctx.fillStyle = color;
    ctx.fillText(
      `${defect.defect_type} (${(defect.length * 100).toFixed(1)}cm)`,
      x, y - 5
    );
  });
}

function getColorByType(type) {
  const colors = {
    '渗水': '#00BFFF',
    '裂缝': '#FF4500',
    '破损': '#FFD700',
    '孔洞': '#FF69B4'
  };
  return colors[type] || '#FFFFFF';
}
```

### 2. WebSocket 连接管理

```javascript
class VideoDetectionClient {
  constructor(taskId, sessionId) {
    this.taskId = taskId;
    this.sessionId = sessionId;
    this.ws = null;
  }
  
  connect() {
    const wsUrl = `ws://your-domain/api/v1/detection/video/ws?task_id=${this.taskId}&session_id=${this.sessionId}`;
    this.ws = new WebSocket(wsUrl);
    
    this.ws.onmessage = (event) => {
      const message = JSON.parse(event.data);
      this.handleMessage(message);
    };
    
    this.ws.onerror = (error) => {
      console.error('WebSocket error:', error);
    };
    
    this.ws.onclose = () => {
      console.log('WebSocket closed');
    };
  }
  
  handleMessage(message) {
    switch (message.type) {
      case 'connected':
        console.log('连接成功');
        break;
      case 'frame':
        this.onFrameDetected(message);
        break;
      case 'progress':
        this.onProgress(message);
        break;
      case 'completed':
        this.onCompleted(message);
        break;
      case 'error':
        this.onError(message);
        break;
    }
  }
  
  onFrameDetected(message) {
    // 渲染缺陷标注框
    console.log(`帧 ${message.frame_no} 检测到 ${message.defect_count} 个缺陷`);
  }
  
  onProgress(message) {
    // 更新进度条
    console.log(`进度: ${message.progress.toFixed(2)}%`);
  }
  
  onCompleted(message) {
    // 显示完成提示
    console.log('检测完成', message.defect_summary);
  }
  
  onError(message) {
    // 显示错误信息
    console.error('检测失败:', message.message);
  }
  
  disconnect() {
    if (this.ws) {
      this.ws.close();
    }
  }
}
```

## ⚠️ 重要注意事项

### 1. 数据一致性

- **WebSocket 消息是实时增量通知**，可能出现丢失、乱序、重复
- **HTTP 接口是最终真相源**，断线重连后应通过 `GET /video/{task_id}` 同步状态
- 收到 `completed` 或 `error` 后，任务进入终态，后续消息可忽略

### 2. 断线重连

```javascript
// 断线后重新获取任务状态
async function reconnect(taskId) {
  const response = await fetch(`/api/v1/detection/video/${taskId}`);
  const { data } = await response.json();
  
  if (data.status === 'completed') {
    // 任务已完成，展示最终结果
    showFinalResults(data);
  } else if (data.status === 'processing') {
    // 任务仍在进行，重新建立 WebSocket 连接
    connectWebSocket(taskId, data.session_id);
  }
}
```

### 3. 取消任务的竞态处理

- 用户点击取消后，任务最终状态必须是 `canceled`
- 即使后续收到 `completed` 消息，也应保持 `canceled` 状态
- 如果任务已经是终态（`completed/failed/canceled`），取消操作不应改变状态

### 4. 错误处理

常见错误消息：
- `等待算法 queued 回调超时`: 算法服务未响应
- `queued 后连续无进度消息超时`: 算法处理卡住
- 建议直接展示错误消息原文，不要自行翻译

## 📊 完整示例流程

```javascript
// 1. 上传视频
const formData = new FormData();
formData.append('bridge_id', 1);
formData.append('drone_id', 3);
formData.append('pixel_ratio', 0.5);
formData.append('video', videoFile);

const uploadRes = await fetch('/api/v1/detection/video/upload', {
  method: 'POST',
  body: formData
});
const { data: uploadData } = await uploadRes.json();
const taskId = uploadData.task_id;

// 2. 启动检测
const startRes = await fetch(`/api/v1/detection/video/${taskId}/start`, {
  method: 'POST'
});
const { data: startData } = await startRes.json();
const sessionId = startData.session_id;

// 3. 建立 WebSocket 连接
const client = new VideoDetectionClient(taskId, sessionId);
client.connect();

// 4. 处理实时消息
client.onFrameDetected = (message) => {
  // 在视频帧上绘制缺陷标注框
  drawDefects(canvas, message.defects);
};

client.onProgress = (message) => {
  // 更新进度条
  updateProgressBar(message.progress);
};

client.onCompleted = (message) => {
  // 显示完成提示和统计结果
  showSummary(message.defect_summary);
  client.disconnect();
};

client.onError = (message) => {
  // 显示错误信息
  showError(message.message);
  client.disconnect();
};
```
