# 桥梁检测系统API接口文档

## 1. 接口概述

本接口文档基于桥梁检测系统的需求，设计了完整的 RESTful API 接口，支持用户管理、桥梁管理、无人机管理、图片上传识别、离线视频分析、智能分析、主页信息统计和报表生成等功能。

## 2. 基础信息

- **API基础URL**: `/api/v1`
- **请求方式**: GET/POST/PUT/DELETE
- **数据格式**: JSON
- **认证方式**: Session + Cookie
- **前端配置**: 所有请求需设置 `credentials: 'include'` 以携带Cookie
- **响应格式**:
  ```json
  {
    "code": 200,
    "message": "成功",
    "data": { ... }
  }
  ```

## 3. 认证接口

### 3.1 用户注册
- **URL**: `/api/v1/auth/register`
- **方法**: POST
- **参数**:
  | 字段名 | 类型 | 必填 | 描述 |
  | --- | --- | --- | --- |
  | username | string | 是 | 用户名 |
  | password | string | 是 | 密码 |
  | real_name | string | 是 | 真实姓名 |
  | phone | string | 否 | 手机号 |
  | email | string | 是 | 邮箱 |
- **返回值**:
  ```json
  {
    "code": 200,
    "message": "注册成功",
    "data": {
      "user_id": 1,
      "username": "user1",
      "role": "user"
    }
  }
  ```

### 3.2 用户登录
- **URL**: `/api/v1/auth/login`
- **方法**: POST
- **参数**:
  | 字段名 | 类型 | 必填 | 描述 |
  | --- | --- | --- | --- |
  | username | string | 是 | 用户名/邮箱 |
  | password | string | 是 | 密码 |
- **返回值**:
  ```json
  {
    "code": 200,
    "message": "登录成功",
    "data": {
      "user": {
        "user_id": 1,
        "username": "user1",
        "real_name": "张三",
        "email": "user1@example.com",
        "role": "user"
      }
    }
  }
  ```
- **说明**:
  - Session自动通过Cookie管理，无需前端手动存储
  - 响应头包含 `Set-Cookie`，浏览器自动保存
  - 后续请求浏览器自动携带Cookie

### 3.3 用户登出
- **URL**: `/api/v1/auth/logout`
- **方法**: POST
- **参数**: 无
- **返回值**:
  ```json
  {
    "code": 200,
    "message": "登出成功"
  }
  ```

## 8. 图片上传识别接口

### 8.1 上传图片
- **URL**: `/api/v1/detection/upload`
- **方法**: POST
- **Content-Type**: `multipart/form-data`
- **参数**:
  | 字段名 | 类型 | 必填 | 描述 |
  | --- | --- | --- | --- |
  | image | file | 是 | 图片文件 |
  | bridge_id | int | 是 | 关联桥梁ID |
  | model_name | string | 是 | 模型名称/版本 |
  | model_type | string | 否 | 分割模型类型，支持 `student` / `teacher`，默认 `student` |
  | pixel_ratio | float | 是 | 像素实际系数 |
- **返回值**:
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {
      "total_defects": 2,
      "image_path": "images/abc.jpg",
      "result_path": "results/def.jpg",
      "processing_time": 5.23,
      "persistence_status": "pending",
      "persistence_task_id": "det_abc123",
      "defects": [
        {
          "id": 0,
          "bridge_id": 1,
          "defect_type": "裂缝",
          "image_path": "images/abc.jpg",
          "result_path": "results/def.jpg",
          "bbox": "{\"x\":120,\"y\":80,\"width\":300,\"height\":40,\"yolo_coords\":[0.5,0.3,0.1,0.08]}",
          "length": 1.25,
          "width": 0.16,
          "area": 0.2,
          "confidence": 0.92,
          "detected_at": "2026-04-16T16:00:00+08:00"
        }
      ],
      "defect_summary": {
        "裂缝": 2
      }
    }
  }
  ```

- **说明**:
  - 后端会先调用算法检测接口，再调用算法分割接口。
  - 调用算法分割接口时会额外传递 `model_type` 给 `/algo/segment`。
  - 图片检测结果采用“同步检测 + 异步持久化”模式，`persistence_status` 可能先返回 `pending`。
  - `defects[].id` 在持久化完成前可能为 `0`，正式入库 ID 需通过持久化状态接口查询。

### 8.2 查询图片检测持久化状态
- **URL**: `/api/v1/detection/persistence/{task_id}`
- **方法**: GET
- **参数**: 无
- **说明**: 查询图片检测任务的异步持久化进度（用于前端轮询）
- **返回值示例**:
  ```json
  {
    "code": 200,
    "message": "成功",
    "data": {
      "task_id": "det_abc123",
      "status": "completed",
      "image_path": "images/abc.jpg",
      "result_path": "results/def.jpg",
      "saved_defect_ids": [101, 102],
      "error_message": ""
    }
  }
  ```

## 9. 离线视频分析接口

- **业务说明**:
  - 当前仅支持“上传本地视频文件后分析”的模式。
  - 当前不支持直接传 `drone_id`、`stream_url`、RTSP 地址或无人机直播流来启动检测。
  - 前端接入顺序固定为：`upload` 上传视频 -> `start` 创建分析会话 -> 建立 WebSocket 接收逐帧结果。
  - WebSocket 中逐帧返回的 `defects` 是当前帧观测结果，不等同于桥梁历史缺陷；历史缺陷以任务汇总和缺陷列表页中的确认结果为准。

### 9.1 上传视频任务
- **URL**: `/api/v1/detection/video/upload`
- **方法**: POST
- **Content-Type**: `multipart/form-data`
- **参数**:
  | 字段名 | 类型 | 必填 | 描述 |
  | --- | --- | --- | --- |
  | video | file | 是 | 视频文件，支持 `mp4/avi/mov` |
  | bridge_id | int | 是 | 关联桥梁 ID |
  | model_name | string | 否 | 模型名称，默认 `baseline` |
  | pixel_ratio | float | 是 | 像素实际系数 |
  | fps | float | 否 | 提帧速率，默认 `1` |
  | enable_segment | bool | 否 | 是否启用分割量化，默认 `false` |

- **返回值**:
  ```json
  {
    "code": 200,
    "message": "视频上传成功",
    "data": {
      "task_id": "video_abc123",
      "status": "uploaded",
      "video_path": "videos/abc123.mp4"
    }
  }
  ```

### 9.2 创建分析会话
- **URL**: `/api/v1/detection/video/{task_id}/start`
- **方法**: POST
- **参数**: 无
- **说明**:
  - 仅 `uploaded` 状态任务允许调用
  - 调用成功后只创建分析会话，不会立即返回处理画面
  - 后端会返回 `session_id` 和 WebSocket 地址，前端连上 WebSocket 后任务才真正开始处理

- **返回值**:
  ```json
  {
    "code": 200,
    "message": "分析会话创建成功",
    "data": {
      "task_id": "video_abc123",
      "session_id": "session_xyz789",
      "status": "ready_to_process",
      "ws_url": "/api/v1/detection/video/ws?task_id=video_abc123&session_id=session_xyz789"
    }
  }
  ```

### 9.3 查询视频分析任务
- **URL**: `/api/v1/detection/video/{task_id}`
- **方法**: GET
- **参数**: 无
- **说明**: 前端用于轮询任务状态、刷新进度、页面重进后恢复任务信息

### 9.4 取消视频分析任务
- **URL**: `/api/v1/detection/video/{task_id}/cancel`
- **方法**: POST
- **参数**: 无

- **参数**:

  | --- | --- | --- | --- |
  | report_name | string | 是 | 报表名称（1-200字符） |
